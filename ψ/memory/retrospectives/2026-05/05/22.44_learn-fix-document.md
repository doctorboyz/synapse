## Lessons Learned

1. **Deep learning reveals hidden bugs** — การวิเคราะห์ codebase อย่างเป็นระบบเปิดเผย QdrantStore.search() bug ที่รับ params แต่ไม่ใช้ ซึ่งเป็นปัญหาที่ไม่มี test จับได้เพราะ Qdrant ถูกตั้งเป็น None เสมอ บทเรียน: mock tests มีคุณค่าสำหรับ code paths ที่ integration tests ไม่ครอบคลุม

2. **Fixture consolidation คุ้มค่า** — การรวม fixtures เข้า conftest ลดจำนวน code ซ้ำจาก ~130 บรรทัดเป็น ~50 บรรทัด และทำให้เพิ่ม api_client fixture ได้ง่าย ซึ่งเปิดทางให้เขียน API route tests ได้ทันที

3. **Technical debt สะสมเงียบๆ** — V1 tests พังอยู่แล้ว 16 ไฟล์ แต่ไม่มีใครรู้เพราะไม่มี CI รัน tests อัตโนมัติ บทเรียน: ถ้าไม่มี CI ที่รัน tests อัตโนมัติ tests ที่พังจะไม่มีใครรู้ และจะสะสมเป็นหนี้เทคนิค
